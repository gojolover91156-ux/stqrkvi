STQRKVI LOCAL WEBSITE

1. Extract the entire ZIP using Extract All.
2. Open the extracted folder. You must see index.html and start.bat together.
3. Double-click start.bat.
4. Visit http://localhost:8000.

If the browser shows 'Directory listing for /', you started the server in the wrong folder. Stop it with Ctrl+C, open the folder containing index.html, and run start.bat there.
Python 3 is required. This is a static capture; original server-side features are not included.
